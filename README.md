## 📖 About

This portfolio website is built using **HTML**, **CSS**, and **JavaScript**. It showcases my journey as a software developer, highlighting my technical skills, featured projects, professional experience, and contact information.

---

## 🛠️ Built With

* HTML5
* CSS3 (Custom styling, no frameworks)
* JavaScript (Typing animation & interactive navigation)
* Google Fonts (Inter)
* Font Awesome (CDN Icons)
